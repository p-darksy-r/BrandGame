# Ícones Windows

Esta pasta reúne os ficheiros `.ico` próprios do projeto:

- `BrandGame.ico`: ícone incorporado no jogo `BrandGame.exe`.
- `update.ico`: ícone incorporado no atualizador `update.exe`.

Os SVGs originais editáveis estão em `src/branding/`. Executa `npm run build:icons` para regenerar os ICOs em 16, 24, 32, 48, 64, 128 e 256 px e atualizar os hashes em `src/branding/manifest.json`. Depois executa `npm run build:web` e `npm run check:web`.

Os ícones originais pertencem a p-darksy-r; consulta `COPYRIGHT.txt` na raiz para os direitos aplicáveis. Os logótipos de marcas usados nas perguntas mantêm as respetivas origens e licenças em `src/web/licenses/`.
